# Duskfall
1. Upload this whole folder to a new GitHub repo (branch `main`).
2. Open the repo > Actions > "Build APK" (it also runs on every push).
3. When it finishes, open the run and download the `Duskfall-APK` artifact, unzip it, and install `app-debug.apk` on the phone.
4. On first launch, allow access to music and audio. New audio files appear on their own.
